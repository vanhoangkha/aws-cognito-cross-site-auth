# 🔐 AWS Cognito Cross-Site Authentication

Single Sign-On implementation across multiple domains using Amazon Cognito.

## Overview

This workshop demonstrates how to implement cross-site authentication using Amazon Cognito, enabling users to sign in once and access multiple web applications across different domains.

## Architecture

- **Amazon Cognito** — User pool and identity pool for authentication
- **AWS Lambda** — Token validation and session management
- **API Gateway** — Secure API endpoints
- **S3 + CloudFront** — Static website hosting

This is a hands-on workshop from the **AWS First Cloud Journey** series.
